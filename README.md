# Maple email assets

Images for Maple email signatures, served through jsDelivr:

- `signature-wordmark.png` (tag `v1`): the grey Maple wordmark, 328×64 (shown at 82×16).
- `signature-wordmark-lg.png` (tag `v2`): the same, taller for the contact card, 452×88 (shown at 113×22).
- `signature-wordmark-coral.png` and `signature-wordmark-lg-coral.png` (tag `v3`): both sizes in Maple coral `#ff9771`.
